# Will 的数学错题医院 · Will's Math Mistake Clinic

一个为本子批改错题定制的小数除法/混合运算错题讲解网站。目前已整理 **2 批共 4 张卷子**：红框圈出的 **11 道**错题 + 卷④荧光笔标黄的 **1 道**新题（单价比较），合计 **12 道错题**，每道配套 **3 道举一反三**，共 **36 道**巩固练习。

> 标记说明：红框 = 做错的题；荧光笔标黄 = 不会做/没做完的题。两者都纳入讲解。若同一题在不同卷子重复出现（如 3.99÷9.5），只收录一次并加"🔁 再遇同款"标记。

## 怎么打开

直接**双击 `index.html`**（用 Chrome / Edge / Safari 打开即可），无需联网、无需安装任何东西。

> 也可以起一个本地服务：在本目录运行 `python3 -m http.server 8080`，然后浏览器访问 `http://localhost:8080`。

## 每道错题的页面包含

1. **原题重现**（英文原题 + 中文翻译 + 卷面订正答案 + **📸 查看 Will 真实卷面实拍笔迹**）
2. **深入浅出的原理讲解**（生活化类比）
3. **正确解法逐步骤** + 记忆口诀
4. **易错点病历分析**（典型错解 → 为什么大脑会这样想 → 防错方法）
5. **互动实验室**（可视化演示）：
   - 小数点联动搬家（拖动看"商不变"，还能演示"只移除数"的坏事）
   - 长除法逐步动画（含验算演示，0 一步一步亮出来）
   - 速度实验室（拖动路程/时间，看_runner_跑起来）
   - 时钟换算 + 倒数视角（0.6h=36min；km/min 与 min/km 互为倒数）
   - 分配律积木（7.6 份 + 3.4 份 − 1 份 = 10 份，看隐藏的 ×1）
   - 运算顺序三级火箭（括号→乘除→加减逐级点火）
   - 单价比较比价台（Pack A vs Pack B，单价法与放大法比对）
6. **3 道举一反三**：在线作答即时判对错、可看提示/解析/竖式动画，全对得 ⭐
7. **游戏化音效反馈**：Web Audio 原生合成器和弦与提示音（支持右上角静音开关）

## 进度

练习完成情况自动保存在浏览器本地（localStorage），全对 3 题即"治愈"该病人 ✅。换浏览器或清缓存会重置。

## 添加下一批错题

把新的练习卷照片发过来即可，按同样的格式在 `js/data*.js` 中追加错题数据（题目、讲解、易错点、3 道练习），网站会自动纳入进度统计。

## 技术说明

纯静态网站（HTML + CSS + 原生 JS），无框架、无构建、无外部依赖；核心竖式动画由 `js/division.js` 的通用长除法步骤生成器驱动。质量保障：穷举测试套件 `node tests/exhaustive.node.js`（1366 条断言：schema/答案 oracle/竖式不变量/全站文案算式求值/一致性闭合），方法论见 **[TESTMETHOD.md](TESTMETHOD.md)**（可移植到任何数据驱动内容型项目），push/PR 由 GitHub Actions 自动执行。
